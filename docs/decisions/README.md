# Architecture Decision Records (ADRs)

Create ADRs only for **significant** decisions that future contributors may need to understand or revisit.

Suggested filename: `0001-short-decision-title.md`.

Suggested structure:

```markdown
# ADR 0001: Decision title

- Status: Proposed / Accepted / Superseded
- Date: YYYY-MM-DD

## Context
What problem or constraints prompted this decision?

## Decision
What was chosen?

## Alternatives considered
What meaningful alternatives were evaluated?

## Consequences
What tradeoffs, migration work, or future constraints follow?
```

Link relevant ADRs from `docs/architecture.md`. Do not record routine implementation details as ADRs.
